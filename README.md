## 📌 Project Overview

The **Independence Day 2026 Event Management System** is a Python and MySQL-based application developed by **Yuvraj Nishad** to manage and organize Independence Day events efficiently.

The system provides a complete solution for managing:

- 🎉 Events
- 👥 Participants
- 🙋 Volunteers
- 📋 Attendance
- 📊 Reports and Data Analysis

The application is developed using **Python** with **MySQL** as the backend database. **Pandas** is used for data analysis, and **Power BI** is used to create an interactive dashboard for visualizing event and attendance data.

This project demonstrates practical knowledge of **Python programming, SQL, MySQL database connectivity, CRUD operations, data analysis, and business intelligence**.

---

## 🎯 Project Objectives

The main objective of this project is to develop a practical Event Management System for managing Independence Day events and their related data.

The project focuses on:

- Managing multiple Independence Day events
- Registering participants
- Managing event volunteers
- Recording participant attendance
- Generating attendance reports
- Storing data using MySQL
- Performing data analysis using Pandas
- Creating an interactive Power BI dashboard
- Implementing CRUD operations using Python and SQL
